# User guides

## Summary

This is the front page of the user guides. There are two guides, one for
each way of running a node, and they have the same sections in the same
order, so a topic sits in the same place in both:

- **[The GUI guide](gui/index.md)**: `poon-gui`, the app you use with a
  mouse in your browser. Start here if you have not used a terminal much.
- **[The headless guide](headless/index.md)**: `poon`, the command-line
  tool. Use it on a server, in scripts, or when you prefer typing.

Both run the same code. Anything you do in the GUI runs the same
command the headless tool would, so the two never disagree, and you can
switch between them at any time with the same files.

[Concepts](concepts.md) explains the words both guides use (series,
mints, pools, ledgers, entries, layers, weight, node policy) in plain
language. Read it once if a word is new to you.

## How the guides are arranged

| Section | What it covers |
| --- | --- |
| 1. Start here | Install, first run, your first wallet |
| 2. [Concepts](concepts.md) | The ideas, in plain words (shared by both guides) |
| 3. How to (basic) | Receive, send, check a balance, back up a wallet, cold keys |
| 4. How to (everyday) | Follow mints, browse the ledger, peers, run, stop and update |
| 5. How to (advanced) | Claim a mint, grind (CPU and GPU), the bounty market, shared wallets, inbound peers, moving a node, several nodes |
| 6. Reference | Every screen or command, and every setting |
| 7. Troubleshooting | What to do when something does not work |

Pages with the same file name in the two guides cover the same topic,
so `gui/3-how-to-send.md` and `headless/3-how-to-send.md` are twins.

Names you will see, such as the network's name, the currency's name and
the built-in series, are placeholders until the project picks them.
