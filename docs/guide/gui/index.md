# The GUI guide

## Summary

This guide shows you how to use `poon-gui`, the app for running a node
and a wallet from your browser. It goes from installing it to the
advanced features, one task per page, and each page says what to click.

TLDR: download `poon-gui`, start it, go to **Node** and press **Write
policy** then **Start node**, go to **Wallet** and create a wallet. After
that, every task below is a page.

The GUI runs the same code as the headless tool `poon`. Where the GUI
leaves something to the terminal, the page links to its twin in the
[headless guide](../headless/index.md). The words used here are explained
in [Concepts](../concepts.md).
